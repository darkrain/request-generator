# Общие Цели Спецификаций

Этот документ описывает цели, общие для всех спецификаций request-generator.

## Цели

- Позволить frontend использовать API-driven метаданные без hardcoded логики конкретного модуля.
- Сделать request-generator источником описания того, как модуль должен отображаться и редактироваться.
- Сохранять существующую модель действий request-generator: `list`, `add`, `view`, `update`, `delete`, `defrec`.
- Описывать межмодульные сценарии через метаданные, если они нужны для визуального поведения.
- Фиксировать права, доступные поля, фильтры, сортировки, действия, ошибки и workflow в API-контракте, а не в клиентских догадках.
